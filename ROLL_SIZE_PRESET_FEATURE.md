# Roll Size Preset Feature - Added to Batch Tag Console

## Feature Added

I've successfully added the "Roll Size Preset" option to the Batch Tag Console as requested. This feature allows you to select from common label sizes for printing.

## Changes Made

### 1. Roll Size Presets Defined
Added common label size presets:
- Standard (100x50mm)
- Small Roll (70x35mm)
- Large Roll (120x60mm)
- Mini Roll (50x25mm)
- Wide Roll (100x30mm)
- Square Tags (50x50mm)

### 2. UI Integration
- Added a "Roll Size Preset" dropdown in the Batch Tag Console header
- Positioned next to other controls for easy access
- Shows preset names clearly

### 3. Dynamic Label Sizing
- Labels now render with the selected dimensions
- Width and height are dynamically adjusted based on preset selection
- Proper CSS styling maintains label appearance

### 4. PDF Generation Updated
- PDF layout adapts to the selected label size
- Calculates how many labels fit per page based on dimensions
- Optimizes placement for efficient paper usage
- Handles portrait/landscape orientation automatically

## How to Use

1. Open **Inventory Management** → **Batch Tag Console**
2. Look for the **"Roll Size Preset"** dropdown in the header
3. Select your desired label size from the options
4. The preview will update to show the new dimensions
5. Click **"Download Master PDF"** to generate labels in your selected size
